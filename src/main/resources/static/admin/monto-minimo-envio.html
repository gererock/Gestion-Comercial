¿Cómo funciona?

1
Monto configurado

El comercio define el importe mínimo necesario para solicitar envío.

2
Compra del cliente

El checkout utilizará esta configuración para evaluar si el carrito alcanza el mínimo requerido.

3
Configuración en cero

Un valor de $0 significa que no existe un importe mínimo de compra para envío.

La disponibilidad final del envío también dependerá de las localidades habilitadas para el comercio.
